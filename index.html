    // HOW IT WORKS

    이렇게 돌려받아요

    1. 추천 코드 복사거래소 카드에서 COGU 추천 코드를 누르면 바로 복사됩니다.
    2. 가입하고 본인 인증가입 화면에 코드를 넣고, 본인 명의로 인증(KYC)을 마칩니다.
    3. 거래하면 자동 지급거래할 때마다 수수료 일부가 정해진 시간에 거래소 지갑으로 들어옵니다.

    // FAQ

    자주 묻는 질문

    페이백이 뭔가요?

    거래소는 추천 코드로 가입한 회원의 수수료 일부를 추천인에게 지급합니다. COGU는 그 몫을 회원님께 다시 돌려드립니다.

    안전한가요?

    모든 혜택은 각 거래소의 공식 추천 프로그램으로 지급됩니다. COGU는 계정 비밀번호나 자산에 접근하지 않고, 그런 정보를 요청하지도 않습니다.

    이미 다른 추천인으로 가입했어요.

    일부 거래소는 고객센터를 통해 추천인 변경이 가능합니다. 거래소 카드의 ‘가이드’에서 ‘기존 계정’ 탭을 확인해 주세요.

    페이백은 어디로 들어오나요?

    가입한 거래소 계정의 지갑으로 직접 들어옵니다. 지급 주기는 왼쪽 표를 확인해 주세요.

    가입할 때 주의할 점은요?

    반드시 본인 명의로 가입하고 본인 인증을 완료해 주세요. 타인 명의 계정은 페이백이 제한되고 계정이 정지될 수 있습니다.

    궁금한 건 바로 물어보세요

    가입, 본인 인증, 페이백 확인까지 1:1로 도와드립니다.
